# Thực Hành Lập Trình Hướng Đối Tượng (OOP Labs)

Chào mừng đến với thư mục lưu trữ các bài tập thực hành môn Lập trình Hướng đối tượng. Thư mục này chứa toàn bộ mã nguồn và tài liệu liên quan đến các buổi Lab trong khuôn khổ môn học.

## Môi Trường & Công Cụ Phát Triển
- **Ngôn ngữ lập trình:** Java (phiên bản Java 8)
- **IDE sử dụng:** IntelliJ IDEA 
- **Công cụ thiết kế UML:** Astah

## Cấu Trúc Thư Mục
Kho lưu trữ này được chia thành các thư mục tương ứng với từng buổi thực hành (Lab):

## Tiến Độ Của Tôi

- [x] **Lab 01:** Environment Setup & Java Basics.
- [x] **Lab 02:** Problem Modeling and Encapsulation.
- [ ] **Lab 03:** Basic OO Techniques.
- [ ] **Lab 04:** Inheritance Polymorphism.
- [ ] **Lab 05:** GUI Programming.

## Hướng Dẫn Chạy Mã Nguồn
1. Clone repository này về máy:
   ```bash
   git clone [URL_repository_của_bạn]
   ```
2. Mở thư mục dự án bằng IDE của bạn (Eclipse, IntelliJ, v.v.).
3. Cấu hình JDK cho project.
4. Tìm đến các class có chứa hàm `main` và nhấn Run để chạy chương trình.

## Ghi Chú
- Các mã nguồn trong kho lưu trữ này là kết quả học tập và thực hành cá nhân.
- Xin vui lòng không sao chép trực tiếp cho các mục đích nộp bài kiểm tra/đánh giá nếu không được cho phép.
